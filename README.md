# The Golden Spoon 金湯匙 Halal Restaurant

Bilingual (English / 繁體中文) website for The Golden Spoon 金湯匙 Halal Restaurant — authentic Pakistani & Indian halal cuisine in Minxiong, Chiayi County, Taiwan.

- Single-file site: `index.html` (no build step)
- Menu, hours, address and phone taken from the restaurant's Google Maps listing and owner-posted menu (May 2026)
- All image slots are configured in `CONFIG.images` inside `index.html` — paste approved photo URLs to replace the placeholders
